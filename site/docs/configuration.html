Providers, models, the CLI, and where everything lives on disk.

CLI commands

CommandWhat it does
codar init --provider <name> --model <modelId> Create your workspace and the chief bot. Optional flags: --base-url (custom/OpenAI-compatible endpoint), --api (pi KnownApi type), --thinking (thinking level).
codar startStart the host: API on 127.0.0.1:7600, web workstation served from the same port.
codar statusIs the host alive? How many bots are up?
codar stopSend SIGTERM to the host.

Providers and models

Codar Bot is bring-your-own-model. Each bot declares its provider and model — mix them freely (a fast coordinator on a flash model, writers on deeper ones). Providers speak the OpenAI-compatible protocol by default; presets exist for Zhipu (zai) and MiniMax.

API keys are written to your local data directory during init and passed to bots as environment variables at spawn time. They are never sent anywhere except your chosen provider.

Data directory

PathContents
~/.codar-bot/Default data root (override with CODAR_BOT_HOME).
~/.codar-bot/work/<name>Recommended work directories for bots (any absolute path works).
~/.codar-bot/audit.jsonlThe append-only audit log.
~/.codar-bot/usage.sqliteThe token/cost ledger behind budgets and meters.

Environment variables

VariableEffect
CODAR_BOT_HOMEUse a different data root (handy for tests and demos).
CODAR_BINDBind address for the API (default 127.0.0.1; 0.0.0.0 for containerized deployments).
CODAR_API_TOKENRequire Authorization: Bearer on API endpoints — for non-local deployments.
CODAR_MEMORY_REVIEW_EVERYHow often bot memory is auto-reviewed (measured in settled turns).
Docker is optional. By default bots run as local processes behind the approval gate — same trust model as popular coding agents. If you want stronger per-bot isolation and Docker is installed, you can run each bot in its own container; the compose layout ships with the repository.

Runtime

Codar Bot runs on the pi agent runtime (pinned at 1.5.0). With npm 7+ it is installed automatically as a peer dependency; with other package managers, install it explicitly alongside.
