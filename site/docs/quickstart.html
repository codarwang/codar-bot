Quickstart

From zero to a working bot team.

Two paths below — pick by comfort, not by profession. Both end in the same place: a bot finishes real work in your chat room.

Path A — I write code

You need Node.js 22.19+ and one provider API key (Zhipu, MiniMax, or any OpenAI-compatible endpoint).

# 1 — install (npm 7+ also installs the pi runtime for you)
$ npm i -g codar-bot
 
# 2 — initialize your workspace and chief bot
$ codar init --provider zai --model glm-4.7
# (your API key goes into ~/.codar-bot — never leaves your disk)
 
# 3 — start the host and open the workstation
$ codar start
✓ web workstation at http://127.0.0.1:7600

In the workstation: give your chief bot a writer to delegate to, then type a task into the room. Watch the handoff happen — and when a bot wants to write a file, you'll get an approval card. That's the product.

Path B — I don't write code

Never used a terminal? Here's the whole idea in plain words: a terminal is a window where you type commands instead of clicking. You'll type five short lines, total. Ready?

  1. Get a key. A provider API key is like a pre-paid card for AI models. Sign up at a provider (for example Zhipu's open platform), create a key, copy it — it looks like xxxx.xxxx. Keep it private: it's the one thing that spends money.
  2. Open the terminal. On macOS: press ⌘+Space, type Terminal, press Enter. On Windows: open PowerShell.
  3. Install Node.js (the engine Codar Bot runs on) from nodejs.org — the "LTS" download, default options.
  4. Install Codar Bot. In the terminal, type this line and press Enter:
    $ npm i -g codar-bot
  5. Set up and start. Two more lines:
    $ codar init --provider zai --model glm-4.7
    $ codar start

    The terminal will ask for your API key when it needs it — paste it and press Enter.

  6. Open the workstation. Double-click the address the terminal prints (http://127.0.0.1:7600) or type it into your browser. You're in the chat room. Say hello — your chief bot answers.
When a bot asks to write a file, you'll see an Allow / Deny card in the chat. This is the approval gate — nothing touches your disk unless you click Allow. Try both buttons once; it's your room.
Spending safety. Every bot and room has a budget. When it runs out, the room pauses — it can't quietly overspend. See Governance to set your own caps.
