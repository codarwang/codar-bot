Extending

Approval rules, bot memory, the REST API — and the honest list of what Codar Bot deliberately is not.

Approval rules, beyond the UI

Standing rules live as JSON and are hot-reloaded — edit them while the host runs and the next tool call already sees the new rules. Global rules apply to every bot; per-bot rules layer on top; deny beats allow at every tier. The workstation and the REST API both expose the merged, effective view (GET /api/rules, GET /api/rules/:botId/merged).

The most common rule shape is a path prefix: "writes under /abs/path/notes/ are allowed", "anything touching .env is denied". Prefixes are matched against absolute paths as stored by the gate.

Bot memory

Bots remember across sessions in three scopes — bot (private to one bot), room (shared by everyone in a chat), and team (shared across the whole team). Memory is plain files under your data root: readable, editable, yours. The host periodically invites bots to review and consolidate what they've written — on a throttled schedule, with the review cost counted against the same budgets as real work.

The REST surface

The workstation is just a client of a local HTTP API. Everything the UI does — rooms, bots, messages, budgets, rules, audit, works — is available at http://127.0.0.1:7600/api/*, including an SSE stream of live events. Script it, dashboard it, wire it into your own tools. For non-local deployments, put it behind CODAR_API_TOKEN auth.

What Codar Bot is not

Scope discipline is a feature. On purpose, Codar Bot is not:

Not thisWhy
A hosted serviceSelf-hosted only. Your keys, your data, your machine — that's the product.
A bridge into IM apps (Feishu / Telegram / WeChat)The workstation's group chat is the surface. No third-party channel risk or ToS gray zones.
Multi-tenantOne operator, one machine. Team features may come later; multi-user SaaS is not the direction.
A fork of piCodar Bot uses the pi runtime's public extension surface only. Upgrades are version bumps, not patches.

Contributing

Issues and PRs are welcome at github.com/codarwang/codar-bot. The test suite is fully offline and deterministic — no network, no real model calls — so a green run on your laptop means the same on CI.
